# Блоки редактора

Страницы сайта собираются в стандартном редакторе WordPress (Gutenberg) из блоков темы `kipora`. Конструкторы вроде Elementor не используются: блоки — обычный код темы, сайт не зависит от сторонних плагинов.

## Как устроен блок

Каждый блок лежит в своей папке `wp-content/themes/kipora/blocks/<имя>/`:

- `block.json` — название, описание и поля блока (тексты, фото, ссылки);
- `render.php` — разметка блока на сайте.

Редакторская часть всех блоков — один скрипт без сборки, `assets/js/blocks.js`. В редакторе блок рисуется теми же классами, что и на сайте, поэтому стили темы показывают его почти как на сайте. Тексты правятся прямо на странице, фото меняются кликом, ссылки и описания фото — в боковой панели.

Блоки динамические: в странице хранятся только значения полей, разметку собирает `render.php`. Поэтому вёрстку можно менять, не трогая сохранённые страницы и не ломая их в редакторе.

Общие функции вывода — в `inc/blocks.php`:

- `kipora_block_text()` — текст из редактора, разрешены только курсив и перенос строки;
- `kipora_block_heading()` — заголовок раздела с волнистой линией;
- `kipora_block_image()` — фото из медиатеки или исходное фото темы (`assets/img/<имя>.jpg|webp`), если клиент его не заменил;
- `kipora_block_url()` — ссылка кнопки; пустая ведёт на страницу KIPORA (калькулятор, контакты) на языке текущей страницы.

## Блоки

| Блок | Что внутри | Дочерние блоки |
| --- | --- | --- |
| Первый экран `kipora/hero` | строка над заголовком, заголовок, текст, кнопка, фото или видео | Карточка услуги `kipora/hero-card` |
| Фото и список `kipora/problem` | фото, заголовок, цитата | Пункт списка `kipora/point` |
| Шаги `kipora/steps` | заголовок, подпись между линиями | Шаг `kipora/step` |

| Список и фото с карточкой `kipora/memory` | заголовок, текст, большое фото, маленькая карточка | Пункт списка `kipora/point` |
| Вопросы и ответы `kipora/faq` | заголовок, текст и ссылка под вопросами | Вопрос `kipora/faq-item` |
| Шапка страницы `kipora/page-intro` | заголовок страницы (h1), текст, кнопка в калькулятор с предвыбором, вторая ссылка, фото | — |
| Прайс `kipora/prices` | цены из настроек калькулятора: уход, цветы, доп. работы, питомцы, урны, страница памяти | — |
| Карточка кладбища `kipora/cemetery` | адрес, район, площадь, кто управляет, ссылки на карту, маршрут и портал kalmistud.ee, заказ с этим кладбищем | — |
| Карточки подстраниц `kipora/page-list` | список подстраниц (кладбища, услуги для питомцев) с отрывками | — |
| Контакты `kipora/contacts` | почта, телефон и адрес из KIPORA → Настройки | — |
| Форма обратной связи `kipora/contact-form` | форма сообщения с вложениями, заголовок и подсказка | — |

Номера пунктов и шагов ставит CSS-счётчик, поэтому после перестановки они идут по порядку сами.

Набор блоков, доступных в редакторе, задаёт фильтр `allowed_block_types_all` в `inc/blocks.php`: блоки KIPORA и базовые блоки WordPress для текстовых страниц. Новый блок с префиксом `kipora/` попадает в список автоматически.

## Как добавить блок

1. Создать папку `blocks/<имя>/` с `block.json` (`apiVersion: 3`, `category: kipora`, `textdomain: kipora`, `render: file:./render.php`) и `render.php`. Корневому элементу дать класс `kp-block`: тогда на страницах он занимает всю ширину.
2. Зарегистрировать редакторскую часть в `assets/js/blocks.js`: `registerBlockType('kipora/<имя>', { edit, save })`. Для блоков с дочерними `save` возвращает `InnerBlocks.Content`, для остальных `null`.
3. Стили — в SCSS темы, `npm run build:css`.
4. Подписи — через `__('…', 'kipora')`, перевод в `tools/i18n.py`, затем `python tools/i18n.py`. Скрипт проверяет PHP, JS и `block.json` и пишет переводы для PHP и для редактора (`themes/kipora/languages/*.json`).

Прайс, карточка кладбища и карточки подстраниц в редакторе показываются предпросмотром с сервера. Настройки у них в боковой панели. Цены в прайсе меняются в KIPORA → Цены, там же, где у калькулятора.

На страницах с блоком "Шапка страницы" тема не выводит свой заголовок, а на подстраницах показывает хлебные крошки.

## Внутренние страницы

`python tools/deploy.py --wp structure-pages` создаёт страницы из исследования `docs/seo-research.md` на трёх языках: уход за могилой, свеча и цветы, кладбища и страница каждого кладбища, питомцы (кремация, урны, страница памяти), цены. Связывает их переводами и пересобирает меню шапки и подвала. Факты о кладбищах взяты из et.wikipedia.org и kalmistud.ee (04.10.2026). `--force` перезаписывает тексты страниц.

`python tools/deploy.py --wp about-contact` собирает из блоков страницы "О сервисе" и "Контакты"; прежний шаблон "Kontakt" больше не используется.

## Поиск

В боковой панели страницы есть раздел "В результатах поиска": свой заголовок и описание для Google, отдельно на каждом языке. Пустые поля берут название и отрывок страницы. Скрипты страниц заполняют описание вводным текстом из шапки страницы.

Тема сама выводит описание, теги для соцсетей (Open Graph), разметку организации на главной и вопросов-ответов на страницах с блоком "Вопросы и ответы", хлебные крошки. Личный кабинет и оформление заказа закрыты от индексации и убраны из карты сайта. Всё это в `inc/seo.php`.

## Подпись студии

Подпись "Разработано в Crazy Studio" в подвале — готовый блок из каталога студии, `blocks/crazy-signature/` (порядок встройки в `FRAGMENT.md`). Блок не правится, цвет полёта и шрифт задаются переменными в `_footer.scss`.

## Перенос главной в блоки

`python tools/deploy.py --wp home-blocks` собирает главную из блоков на трёх языках с прежними текстами. Страницы, где блоки уже есть, скрипт не трогает; `--force` пересобирает их заново и стирает правки клиента.
