# Визуальная система KIPORA

## Главная собрана по референсу владельца

01.10.2026 владелец выбрал референсом главный экран https://catskills-showcase.pages.dev/ и попросил взять оттуда шрифты и исполнение. Из референса перенесены:

- композиция по центру: строка преимуществ, волнистая линия, заголовок антиквой с курсивными акцентами, лид, кнопка-"таблетка";
- центральное фото-"стикер" в белой обводке;
- белая линия-росчерк на всю ширину, прорисовывается один раз при загрузке;
- две наклеенные карточки с фото в фигурной маске по бокам;
- шалфейный фон с зерном.

Содержание своё. В центре кладбищенский фонарь со свечой, типичный для эстонских кладбищ; фото вставлено в арку, форма надгробия. Карточки ведут в калькулятор с уже выбранным направлением: уход за захоронением или питомцы. Заголовок написан для тех, кто сам не может приехать на кладбище.

Изображения референса не использованы. Фон-зерно сгенерирован заново, линия и листья нарисованы свои.

## Цвет

| Токен | HEX | Роль |
|---|---|---|
| `--kp-ink` | `#223A28` | Текст |
| `--kp-moss` | `#32573B` | Ссылки, выбранные варианты |
| `--kp-accent` | `#6D910A` | Основные кнопки (белый текст 19 px полужирным: контраст проходит только для крупного текста) |
| `--kp-mist` | `#EAEFD1` | Фон страницы |
| `--kp-moss-wash` | `#F4FFD8` | Заливка зелёной карточки и выбранных вариантов |
| `--kp-candle` / `--kp-candle-wash` | `#976603` / `#FFF6D9` | Второй акцент: карточка питомцев, статусы оплаты |
| `--kp-sticker` | `#FFFFFF` | Обводка "стикеров" |

## Шрифты

- Instrument Serif — заголовки, с курсивом.
- Instrument Sans — интерфейс и текст.

Кириллицы в Instrument нет, поэтому для русской версии через `unicode-range` под теми же именами семейств подключены Oranienbaum (узкая контрастная антиква, ближе всего к Instrument Serif) и Onest. У Oranienbaum нет курсива, браузер наклоняет прямое начертание. Все шрифты лежат на нашем сервере: это требование GDPR.

Курсивные акценты в заголовке главной задаются в заголовке страницы звёздочками: `Hoolitseme *puhkepaiga* eest`. Во вкладке браузера и в меню звёздочки не показываются.

## Фото

Три фотографии главного экрана (`hero-lantern`, `card-grave`, `card-pet`) сгенерированы для проекта 01.10.2026. В теме используются оптимизированные пары JPG/WebP. Изображения не являются фотографиями реальных объектов или животных клиента.

## Мобильная версия

Шапка: логотип, языки и кнопка меню. Меню открывается панелью с крупными ссылками антиквой, как в мобильном меню референса. Карточки встают в ряд под фото. Проверено на ширине 375 px, горизонтальной прокрутки нет.
