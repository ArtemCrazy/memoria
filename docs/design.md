# Визуальная система KIPORA (фаза 1)

## Предмет и тон

KIPORA ухаживает за местами захоронения в Таллине и Харьюмаа и помогает проститься с питомцем. Сайт читают родственники, в том числе живущие далеко, и люди в горе. Главная задача сайта — спокойно показать цену, принять заказ и хранить память.

Первая ассоциация с темой — траурная эстетика: чёрный фон, свечи, голуби, золото. Мы её не берём. Эстонское кладбище — это лес: Metsakalmistu, сосны, мох, гранит, песчаные дорожки. Отсюда светлая, дневная и тихая подача.

## Цвет

| Токен | HEX | Роль |
|---|---|---|
| `--kp-ink` (graniit) | `#26302E` | Текст, тёмные поверхности |
| `--kp-moss` (sammal) | `#4C5F3A` | Основные действия, выбранные варианты |
| `--kp-mist` (udu) | `#EEF1EC` | Фон страницы, холодный серо-зелёный |
| `--kp-paper` (kask) | `#FBFCFA` | Поверхности карточек и форм |
| `--kp-lichen` (samblik) | `#C9D2C0` | Линии, границы |
| `--kp-candle` (küünal) | `#B7832F` | Единственный тёплый акцент: итоговая цена, отметка оплаты |

Кремовый фон и терракотовый акцент не используем: это самый частый шаблон "сгенерированного" сайта.

## Шрифты

- Alegreya — заголовки. Гуманистическая антиква с каллиграфическим ритмом, звучит как надпись, а не как реклама. Кириллица и эстонские õ ä ö ü š ž есть.
- Onest — интерфейс и основной текст. Спокойный гротеск с кириллицей и Latin Extended.

Шрифты подключаются с нашего сервера, а не с серверов Google: это требование GDPR для сайта в ЕС.

Шкала: 16 / 18 / 22 / 28 / 36 / 48 px, межстрочный интервал текста 1.55, длина строки до 70 символов.

## Композиция

Выравнивание по левому краю. Калькулятор устроен как две колонки: шаги слева, итог справа (закреплён при прокрутке). На телефоне итог уходит вниз.

```
┌──────────────────────────────┬──────────────┐
│ 1 Что нужно?  [уход] [питомец]│  Ваш заказ   │
│ 2 Услуга      ( ) ( ) ( )    │  строки      │
│ 3 Размер      ( ) ( ) ( )    │  ────────    │
│ 4 Доп. работы [ ] [ ] [ ]    │  Итого 219 € │
│ 5 Кладбище    [select]       │  [Дальше]    │
└──────────────────────────────┴──────────────┘
```

Шаги пронумерованы, потому что это действительно последовательность.

## Принципы

1. Одна запоминающаяся деталь — схема участков на главной: вид сверху на кладбищенские кварталы с номерами секторов. Она связывает визуал с тем, что клиент указывает в заказе (сектор, номер места). Всё остальное тихое.
2. Никаких надписей капсом, "бровок" над заголовками и стрелок в кнопках.
3. Радиусы по иерархии: у полей и вариантов выбора 6 px, у крупных панелей 12 px, у кнопок 6 px.
4. Анимация только в ответ на действие: выбор варианта и обновление итога.
