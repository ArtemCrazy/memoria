# Подпись студии в подвале (crazy-signature)

Знак, которым студия подписывает сделанные сайты. Не логотип: мышь ведёт себя
живо — вспархивает и возвращается, — но занимает одну строку подвала.

## Что выбрать до установки

Выбор делается в живом примере (кнопки «Режим» и «Набор»), оттуда же берётся
готовая строка разметки. Всего два решения:

**Режим** — атрибут `data-cs-sign`:

| Значение | Поведение | Когда |
|---|---|---|
| `fly` | Сидит рядом с подписью, взлетает по наведению | Основной вариант |
| `hang` | Висит вниз головой на разделительной линии подвала, отцепляется по наведению | Когда подвал отделён линией — блок рисует её сам |

**Набор подписи** — класс-модификатор: без модификатора гротеск (тот же шрифт,
что у сайта), `cs-sign--serif` — антиква, `cs-sign--book` — книжная антиква.
Больше вариантов не заводим намеренно: курсив, разрядка капсом и подпись одной
строкой пробовались и отброшены — в подвале они выглядят хуже, а не иначе.

## Порядок установки

1. **Папка уже скопирована** в проект — `blocks/crazy-signature/`.

2. **Подключи стили и скрипт:**

   ```html
   <link rel="stylesheet" href="/blocks/crazy-signature/crazy-signature.css">
   <script type="module" src="/blocks/crazy-signature/crazy-signature.js"></script>
   ```

   Со сборщиком — то же самое импортом:

   ```js
   import './blocks/crazy-signature/crazy-signature.css'
   import './blocks/crazy-signature/crazy-signature.js'
   ```

   Скрипт находит подписи сам. Если разметка появляется позже (роутер, модалка) —
   позови руками: `initCrazySignature(контейнер)`.

3. **Вставь разметку** из `snippet.html` в подвал, поменяв режим и набор под
   выбранное.

   Строка `<span class="cs-sign__rule">` нужна только режиму `hang` — это
   разделительная линия подвала, за которую цепляется мышь. В остальных режимах
   её можно удалить. Классы `cs-sign__wing` на двух путях SVG обязательны: за
   них цепляется взмах крыльев.

   В самой разметке комментариев нет намеренно — она уезжает в браузер, и
   пояснения увидит любой через «исходный код страницы». Всё, что нужно знать,
   написано здесь.

4. **Подгони под сайт переменными**, сам блок не правь:

   ```css
   .cs-sign {
     --cs-sign-size: 2.625rem;    /* размер мыши */
     --cs-sign-accent: #d97757;   /* цвет в полёте */
     --cs-sign-serif: "Ваша антиква", Georgia, serif;
   }
   ```

   Цвета в покое блок берёт от цвета текста подвала (`currentColor`), поэтому
   на светлом и тёмном фоне он работает без настройки.

## Как это устроено

Мышь — четыре пути SVG: два крыла, уши, тело. Взмах — поворот крыльев вокруг
плеча, полёт — дуга на `translate` + `rotate` у обёртки. Скрипт только вешает
класс `is-flying` и снимает его, когда полёт доигран; всё движение в CSS.

Дальность полёта считается от `--cs-sign-size`, поэтому увеличенная мышь летает
соразмерно — правки ключевых кадров для этого не нужны.

## Чего не делать

⛔ **Не менять `viewBox="5 10 90 34"`.** Точки вращения крыльев
(`transform-origin: 48.4px 12px`) отсчитываются от левого верхнего угла именно
этой рамки. Сдвинешь рамку — крылья начнут вращаться вокруг пустого места.

⛔ **Не снимать класс `is-flying` по уходу курсора.** Полёт должен доигрываться:
иначе мышь застывает в воздухе на полпути, если увести курсор сразу.

⛔ **Не красить акцентом заодно и название студии.** По фирменному стилю акцент
один на работу, и здесь он достаётся моменту взлёта. Название всегда спокойное.

⛔ **Не подбирать позу «висящей» мыши поворотом крыльев вниз, к голове.** Силуэт
разваливается на два отдельных лоскута — проверено на рендерах. Висящая мышь —
это тот же раскрытый силуэт, просто перевёрнутый.

## Живой пример

`demo/index.html` работает от исходников блока, поэтому правки видно сразу — но
**только по http**. Двойным кликом с диска он открывается пустым: страница
подключает скрипт как ES-модуль, а такие браузер по `file://` блокирует. Подними
любой локальный сервер над папкой блока. Собранная страница каталога этим не
страдает — в ней стили и скрипт вшиты копией, она открывается и файлом.

Страница для каталога собирается отдельно:

```bash
node database/fragments/crazy-signature/demo/build-preview.mjs
```

Собирать после каждой правки блока: на деплое это не делается.
